## 操作と今回の範囲

SourceをSampleにしてMorphをOnにする。
Wave A / Wave B / Resultを1つのcanvasへ重ね、Edit A / Edit Bで描く対象を選ぶ。
形状選択・自由描画はdraft、Apply Morphで採用、Revert draftで採用済みA/Bへ戻る。
Resultはそのdraftのblend previewであり、未Apply中は演奏中の波形とは異なる。
通常PCM draftは別に保持する。

Amountは0〜1で、Source内とkeyboard横の2か所を同じhost parameterへbindする。
採用済みA/Bを発音中・Sustain・Releaseにも再発音せずblendする。
A/B Applyはworkerで準備したengineへの交換で、保持音・残響を停止する。
Morph On/Offの実効source変更も停止する。Offは元Builtin / VAB / PCMへ戻す。
Noiseは優先し、Morphの設定は保持する。PMONとの併用は12音のまま。

これはSoftware Morphで、実機SPUの追加回路としては扱わない。
bank0のNoise / PMONと独立したprivate bank1に112-sampleの16bit PCM carrierを用意する。
Gaussian / ADSR / PMON / ReverbはSPUを通し、物理RAM容量は変えない。
Morph Onと元4bit ADPCMの音がbit一致する保証はせず、Offで旧音を保持することを検証する。

Webとの差分は、初期Off、既存PCM形状の振幅0.8を使うA=Sine / B=Saw、
endpoint編集が明示Apply、Offで元sourceへ戻す点。
Webのendpoint即反映 / Offで最後のblend保持とは区別する。
Morph LFO、長いAudioへのMorph、外部入力Reverbは追加しない。
