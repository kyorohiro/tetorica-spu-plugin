## 操作と音源処理

PCMページをSourceへ広げ、Source / ADSR / Reverbの3ページを維持する。
Source: Sampleは従来のSoftware PCM editor、Source: SPU NoiseはNoise clockと説明を表示する。
切替で元Builtin / PCM / VABとローカルPCM draftを変更しない。Sampleへ戻すと元音源を使う。
Automation / host restoreでも表示を更新し、mode変更時は途中strokeを取り消して一度全体を再描画する。

Noise Offが初期状態。共有Noise clockは0〜63、初期48。各instanceの全24voiceで共有する。
Clockだけの変更はSPUCNT bits8..13へ反映し、KON/KOFF・sample位置・ADSR・Noise sequenceをresetしない。
鍵盤とvelocityでADSRを演奏し、SustainとReverbも使用できる。NoteとPitch BendはNoiseを調律しない。
Bend/pedalのlive状態は保持し、Sampleへ戻った後の演奏に使う。固定coreのNoise generatorは近似実装。

Sample / Noiseのmode変更は保持音と残響を即停止する。block境界でmodeを適用し、旧blockから持ち越した
Note On/Offを除く。今blockの新MIDIと持ち越したwheel/pedalは保持する。Clock変更ではNoteを除かない。
既存ADSR・Reverb・volume/panと元Tone send flagを保つ。NoiseもTone send設定に従う。

## one-shot sampleと内部carrier

Noiseの音自体はNativeのNOISE mask / generatorから出すが、decoder cursorには有効なloopが必要となる。
元VABのone-shotを使い続けるとsample ENDでNoiseも止まるため、非audioのconstructorでprivateな
28-frame zero host cacheをloop付きで用意し、全24slotのKON/KOFFをmuteでwarmする。
Noise maskをOffのまま準備するので初期Noise sequenceを進めない。

SPU RAMの0..0x1000はNativeのcapture buffersがrenderで上書きするため、そこへloopを置かない。
private carrierはRAM容量を消費せず、既存最大VAB payloadを減らさない。元RAM sample/cacheを保持する。
Noiseはhost cacheの値を音として出さず、同じvoice renderer内のNoise branchで置き換える。
mode変更後の各slot最初のNote Onだけraw KONで新sourceを即ラッチし、audition fade-inへつなぐ。
旧one-shot ENDまでのfade中に旧sampleを使い続けたりsend bitが消えたりすることを防ぐ。
通常のSample演奏と、Clockだけの変更はこの再ラッチを行わない。

audioでPCM upload / encoder / SDK reset / cache準備を行わず、mode / Clock変更はregisterとmaskだけを変更する。
SPUCNTのReverb bit7とNoise bits8..13はそれぞれ他方を保持する。

## 保存形式と互換性

既存parameter ID0〜16を保ち、SPU Noise17とShared Noise clock18を追加して全19parameterとする。
schema5はfixed80bytes+source。既存72bytesとsource@32の配置を保ち、flags u32@72+Nと
Clock u32@76+Nを追加する。flagsはbit0だけ許可、Clockは0〜63。音源kind0/1/2は変更しない。
schema1/2/3/4とGain-onlyはNoise Off / clock48へ移行し、各旧形式の音源・ADSR・Reverbを保持する。
decode / engine準備 / 全19parameter chunk確保をcommit前に完了し、不正stateは現音源・全設定・正常pendingを保つ。
Noise sequenceのlive内部状態は保存せず、復元時は新しいengineから始める。
