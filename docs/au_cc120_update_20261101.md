CC120のチャンネル別停止に対応したAUを手元へ配置した。

新しい検証copyで保存・完全終了・再起動して復元できた。

開始Pluginは`476bfa9`、実装`0bb1bb7`、作業前TODOは`4b5e0ec`、Native SDKは`95cf71a`。

## 配置済みAUの検証

```sh
python3 scripts/validate_au.py
build/macos/tetorica_au_state_check \
  "$HOME/Library/Audio/Plug-Ins/Components/TetoricaSPU.component"
```

- auvalはexit0、26parameters、`AU VALIDATION SUCCEEDED.`。
  既知の非致命的warning `Preset name is not retained in retrieved class data`は残る。
  ローカルregistryの強制更新は行っていない。
- 実installed bundleを読む48kHz hostはexit0、全15 PASS行。
  全16MIDI channelのCC120、他channelのPCM /controller保持、held /deferred /release停止、
  offset /split /future /同offset fresh NoteOnを確認した。
- nonzero PMONの12組で対象pair停止・survivor PCM・停止pairの再利用を確認。
  共有Reverb tailはCC120なしreferenceとの左右PCM一致を確認した。
- Gain /ADSR /PCM /Noise /PMON /Morph /Web /WAV /Software audio /LoopRepeat /
  embedded stateの既存回帰も成功した。

このhost検証はaudio deviceやeditorを開かない。
unit /sanitizer /VST3 /CIは[実装時の成功記録](cc120_20261101.json)を引き継ぎ、
source不変のため配置作業で全build・全CIは再実行していない。

## GarageBandの保存・再起動

作業dirは`build/au-cc120-update-v1d1boac`。
known source `build/spu-vab-check.band`を`spu-cc120-restore-check.band`へ複製した。
その新copyで保存・完全終了・再起動し、main windowのproject URLと再生・録音停止を確認した。
AU editorは保存前と再起動後に、Embedded VAB /Program 3 /Tone 0 /Gain 99.0% /
Project sound restored、Reverb Off /Morph Offを表示した。

- 保存schema9 payloadは4,768bytesで完全一致。
  SHA256: `35a6b2cd76ff553bd121a87b5a46513cbb78b953da1f673cedd863447fb33e1c`。
- 埋め込みVABは3,744bytesで元fixtureと完全一致。
  SHA256: `71a7de205c0ebe1b8743288d90cd3b0204da9bd81aed9159af31f404d7cf2be6`。
- 保護原本`build/spu-au-check.band`の11files、複製元`build/spu-vab-check.band`の7filesは不変。

開始時に開いていた前回Gain検証copyは、保存前に`pre-save-open-project.band`へ全11filesを退避した。
その既知copyは終了時と新copyへの切替時に意図的に保存したため、project /UI /autosave filesは
変わり得るが、埋め込みpayloadは一致した。退避11filesも保持した。

read-only inspectorは保存XML候補とbytesの検査で、active trackのbindingを解析するものではない。
active instrumentの復元は再起動後の実AU画面で別途確認し、画面・AX記録のhashをJSONへ保存した。
新copyのAU editorを開いたまま、再生・録音停止で残している。
