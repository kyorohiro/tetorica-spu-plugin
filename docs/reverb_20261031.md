## 操作と音源処理

720×620の共通bank / Gain / keyboardを保ち、ADSRとReverbの編集pageを切り替える。
Reverb pageを初期表示する。Offと、Room / Studio Small / Studio Medium / Studio Large /
Hall / Space Echo / Half Echoを選べる。固定coreが認識する近似presetであり、任意register編集や
実機の完全なReverbアルゴリズムは公開していない。

手動で非Off presetを選ぶとEnableもOn、Offを選ぶとOffになる。
automationとhost restoreではpresetとEnableを独立して扱い、保存済みbypassを壊さない。
Return L/Rは0〜100%、初期25%。dryを変えずwetを追加する。
Send: all notesが初期値で、Send: Tone settingは選択VABの元send flagを使う。
元flagはbank / prepared sourceへ独立に保持し、Builtinの元sendはfalse。
無音になる設定の理由はstatusへ表示する。

Enable Offはreturnとsendを0にし、非Off presetの処理は裏で進めて減衰させる。
再Enableは残った履歴から再開する。preset Offは32wordを0にし、残響履歴も消す。
別の非Off presetへの切替は履歴と既存voiceを保つ。
即wet muteとOff時のclearは、sendだけを止める現在のWeb UIからの意図した改善である。

ADSR・pitch・sample位置を変えずblock境界で適用する。one-shot ENDがsend bitを消すため、
各Note Onで要求sendを復元する。Gain/ADSRの既存ID0〜11は維持し、ReverbはID12〜16を追加した。
editorのAll sound off / prepare / deactivate / overflow / VST3 bypassは残響も消す。
後続の[CC120変更](cc120_20261101.md)ではMIDI CC120を対象channelのdry停止へ分離し、共有残響を保持する。

## 保存形式

schema3は72+bank bytes。既存48bytesは維持し、preset@48、flags@52、
Return L@56 / R@64を追加する。returnの保存単位は0〜1のdouble。
preset範囲・未知flags・非finite/範囲外return・exact lengthをcommit前に検証する。
schema1/2とGain-onlyはReverb Offへ移行し、元bankと該当schemaのADSRを保つ。
17parameter chunkの確保とengine準備をcommit前に終える。
不正stateは全parameter・準備済み交換・現在のwet PCMを変更しない。
残響そのものは保存せず、成功したproject restoreは空のeffect履歴から始める。
