## 操作と音源

Sourceの`Sample + PMON`を選び、新しく鍵盤を押す。
even voiceを変調器、隣のodd voiceを元sampleのcarrierとして使うため最大12音。
ModulatorはSine / Triangle / Saw / Square、Ratioは0.01〜16、Depthは0〜1。
波形・Ratio・Depthは保持音・Releaseにも反映し、再発音しない。
Decayは0〜5000ms、0はHold。SPUの近いrateへ丸め、次のNote Onから適用する。
modulatorのReleaseはNote On時のcarrier Releaseに従い、Sustainはpairの離鍵を保留する。

carrierだけをdry / Reverbへ送り、Custom / Tone ADSRもcarrierへ適用する。
PMONはSPUの変調経路を使う。modulatorのPCM生成・live更新はsoftwareで行い、
private host cacheを使う。物理SPU RAMを拡張したものとは扱わない。
WebのADPCM modulatorと波形がbit単位で一致するという保証はしない。

SourceはSample / SPU Noise / Sample + PMONの3択。
元VAB / PCMと未Applyのdraftを保持し、切替で保持音・残響を停止する。
Edit carrier (Sample)でPCM編集へ戻れる。Reverbは独立・初期表示のpageを維持する。
