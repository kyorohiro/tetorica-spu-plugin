## 実装の入口とhost通知

`VabLoader::requestFile(path)`は最初の再生可能Toneを選ぶ。
`requestFile(path, flatTone)` / `requestSelection(source, program, tone)`は選択を厳守し、
`requestProgram(source, program)`はそのProgram内だけを探索する。すべてfileや音源準備はworkerで行う。
サイズの測定・1 MiB検査後にbufferを確保し、exact read / EOF / 読込後サイズを確認する。
同じ長さの任意の並行書き換えに対するfilesystem snapshotを保証するものではない。

UIは`plugin/InstrumentUI.cpp`。定期的なOnIdleがimmutableな定義と世代を読み、
host restoreは成功後にatomic revisionだけを通知する。UI refreshのためのengine再要求はない。
pickerは弱い寿命tokenと開始時のrevision / generationを持つ。popupはeditor内描画を使い、
固定macOS native popupの非同期raw graphics参照を避ける。

hostへの通知はstate/loader lockを解放してから行い、hostの同期的なGetState呼出しを許す。
通知済み・復元済みの定義を基準に比較し、後続requestの失敗で直前の成功通知を取りこぼさない。
同じbank/Program/Toneの再選択と、host restoreをdirty通知しない。
VST3はoptional `IComponentHandler2::setDirty(true)`。
AUのClassInfo listener通知は固定frameworkでprivateだったため、publicな
`InformHostOfPresetChange()`（PresentPreset通知）を使用する。DAW側のdirty判定は要追試。
