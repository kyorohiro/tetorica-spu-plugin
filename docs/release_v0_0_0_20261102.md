## 初回失敗からの修正

実装前TODOは`9d0fbe1`、最初の実装は`da7131e`。
最初の通常CIとWindowsは成功したが、[Mac Preview](https://github.com/kyorohiro/tetorica-spu-plugin/actions/runs/41361594974)はstatic plistに旧versionが残っていたため停止した。
[最初の署名CI](https://github.com/kyorohiro/tetorica-spu-plugin/actions/runs/41361750027)はcodesignとkeychain cleanupで停止し、Appleへの提出には至っていない。

`1e46aa6`でplist / AU metadataを0.0.0へ揃え、一時keychainを署名中だけuser search listへ保持した。
`codesign --keychain`はidentity検索を限定するだけで、chain構築にはsearch listへの登録も必要なため。
cleanupにはAppleのAtomicFile実装に沿う既知lock / atomic companionの検証を追加した。
再CIで`.flD3051040`を実際に観測し、`security delete-keychain`で削除され、cleanupは`cleaned`となった。
失敗診断は固定語彙のみとし、任意のtool output・secret値を公開記録へ出さない。

5つのSecretsはprepare stepだけへ渡し、一時keychain / p12 /公証資格情報をartifactやgitへ含めていない。
ローカル秘密鍵の書き出しやSecrets値の取得は行っていない。
